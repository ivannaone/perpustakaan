# Panduan User

## Registrasi Akun

1. Buka browser, akses halaman aplikasi perpustakaan.
2. Klik **Daftar sekarang** di halaman login.
3. Isi Nama Lengkap, Username, Password, dan Konfirmasi Password.
4. Klik **Daftar**.
5. Akun akan dibuat dengan role `user` secara otomatis.

Setelah mendaftar, kamu akan langsung masuk ke Dashboard User.

Catatan: akun baru belum terhubung ke data anggota perpustakaan.
Hubungi petugas perpustakaan untuk mengaitkan akunmu agar bisa meminjam buku.

## Login

1. Buka halaman login.
2. Masukkan Username dan Password.
3. Klik **Masuk ke Sistem**.
4. Jika berhasil, kamu akan diarahkan ke Dashboard User.

Sesi akan berakhir otomatis setelah 60 menit tidak ada aktivitas.
Kamu akan diminta login ulang saat membuka halaman setelah sesi habis.

## Dashboard User

Dashboard menampilkan:

- Akses cepat ke Katalog, Peminjaman Saya, Profil, dan Informasi.
- Kotak pencarian buku langsung dari halaman utama.
- Empat buku terbaru dari koleksi perpustakaan.
- Ringkasan informasi layanan perpustakaan.

## Melihat Katalog Buku

1. Klik menu **Katalog** di navbar atas.
2. Semua buku yang tersedia ditampilkan dalam bentuk kartu.
3. Setiap kartu menampilkan judul, pengarang, penerbit, tahun, dan jumlah eksemplar tersedia.
4. Gunakan kotak pencarian untuk mencari berdasarkan judul, pengarang, penerbit, atau ID buku.

Status ketersediaan:

- **Tersedia · N eksemplar** — buku bisa dipinjam.
- **Stok Habis** — semua eksemplar sedang dipinjam.

## Mengajukan Peminjaman

Syarat sebelum meminjam:

- Akun sudah dikaitkan dengan data anggota perpustakaan oleh petugas.
- Buku yang dipilih masih tersedia (ada eksemplar berstatus `Ada`).
- Kamu belum sedang meminjam buku yang sama.

Langkah meminjam:

1. Buka halaman **Katalog**.
2. Temukan buku yang ingin dipinjam.
3. Klik tombol **Pinjam Buku** pada kartu buku tersebut.
4. Jika berhasil, muncul pesan konfirmasi dan peminjaman tercatat.
5. Ambil buku fisik di perpustakaan.

Jika akun belum terhubung ke anggota, tombol **Pinjam Buku** akan nonaktif
dan muncul pesan peringatan di bagian atas halaman.

## Melihat Riwayat Peminjaman

1. Klik menu **Peminjaman Saya** di navbar.
2. Semua buku yang pernah dan sedang dipinjam ditampilkan.
3. Setiap kartu menampilkan judul buku, nomor eksemplar, tanggal pinjam,
   tanggal kembali (jika sudah dikembalikan), dan status.

Status peminjaman:

- **Sedang Dipinjam** — buku belum dikembalikan.
- **Sudah Dikembalikan** — buku sudah dikembalikan.

Pengembalian buku dilakukan melalui petugas perpustakaan,
bukan melalui tombol di aplikasi ini.

## Mengelola Profil

1. Klik menu **Profil** di navbar.
2. Halaman Profil menampilkan nama, username, dan role akun.
3. Untuk mengubah nama atau username, isi form di bagian kanan.
4. Klik **Simpan Perubahan**.

Role tidak bisa diubah melalui halaman ini.

## Informasi Perpustakaan

Klik menu **Informasi** di navbar untuk melihat:

- Tentang perpustakaan.
- Layanan yang tersedia.
- Cara mencari buku.
- Informasi peminjaman.
- Jam pelayanan.
- Ketentuan penggunaan.

## Logout

Klik tombol **Keluar** di bagian bawah halaman untuk mengakhiri sesi.
